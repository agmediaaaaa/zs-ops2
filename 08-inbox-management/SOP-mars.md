## OBJECTIVE

Convert every interested reply into either:
1. a **booked calibration call**, or
2. a **controlled sample** that still forces the call before real candidates go out.

You are not here to dump resumes into the thread. You are here to get the info needed to send the *right* people — and that info lives on a short call.

### What “X / Y / Z” means (ask for these)

Pull only what is missing. Do not turn this into a long questionnaire before offering times.

| Need | Why |
|---|---|
| Role / trade | CNC setup, Swiss turn, welder, maintenance, QA, etc. |
| Machine / controls | Haas / Mazak / Doosan / etc. |
| Shift | Day / night / rotating |
| Location / site | Plant, city, remote vs on-floor |
| Target wage / bill range | So we do not send off-market profiles |
| Must-haves | Tolerance, certs, years, clearance (if any) |
| Timing | When the seat needs to be filled |

If they already pasted a full JD covering most of this → confirm receipt, commit the write-up clock, and still ask for a **5–10 min calibration** so the pull matches the floor.

2. Include Matt’s calendar: https://calendly.com/matt-mars-staffing/15min

4. Pause the sequence.

## PATH: NO → DO NOT GO SILENT

If they won’t book yet, use **one** of the two paths below. Goal is still the call.

### Path A — Client sends sample profiles / asks for a call after review

**Trigger:** They say “send a couple examples first,” “show me what you have,” or they share sample resumes / profiles of what “good” looks like and want to talk after.

**Action:**
1. Accept their samples (or ask them to forward 1–2 examples of the bar).
2. Confirm you will match against that bar.
3. Still push a short call before live outreach / candidate offers go out.

```text
Hi {{first_name}},

Got it — send over 1–2 sample profiles that represent the bar (or paste the must-haves), and I’ll mirror that.

Once I have those, the fastest way to pull accurate matches is a quick 10-minute calibration on shift, wage, and machine. After that we can send 2–3 screened write-ups.

Here’s the calendar if easier:
https://calendly.com/matt-mars-staffing/15min

Best,
{{sender_first_name}}
```

---

### Path B — We send AI example resumes (examples only)

**Trigger:** They refuse the call *and* will not share specs / samples, but still want to “see resumes.”

**Action:**
1. Build **example** resumes / write-ups with AI (anonymized, clearly labeled as examples).
2. State plainly: these are **examples**, not live candidates we can put in play.
3. Hard rule language: we **cannot take these offers back to candidates** until a **search agreement** is in place.
4. Close with the call ask — that is how we do company-specific / real profiles.

```text
Hi {{first_name}},

Understood. I’ve attached a couple of **example** profiles so you can see the format and depth we use when we screen craft talent.

Important: these are examples only — not live candidates assigned to {{company_name}}. We can’t take these offers back to candidates, or run a real search against your floor, until we have a search agreement in place.

If you want profiles built specifically for your shop (machine, shift, wage, must-haves), I can only do that after a short call.

Grab 10 minutes here and we’ll lock the specs, then send real screened write-ups:
https://calendly.com/matt-mars-staffing/15min

Best,
{{sender_first_name}}
```

**Operator rules for Path B**
- Never invent a real named candidate as if they are available.
- Never imply the example person can interview this week.
- Always include the **search agreement** line before any “we’ll send people” promise.
- After send: label `INTERESTED`, pause sequence, wait for call or next instruction — do not keep emailing more fake profiles.

## HARD RULES

1. **Call first for real people.** Real candidates / live offers require a calibration call (and a search agreement before we take offers to candidates).
2. **Examples ≠ inventory.** Path B samples are demos of format/quality only.
3. **No blind résumé dumps.** “Just send CNC resumes” without specs = Path A or B, not a zip of random files.
4. **No M&A language.** Never say acquisitions, valuations, EBITDA, multiples, sell-side, PE.
5. **Book with two times + Calendly.** Friction kills the thread.
6. **Same mailbox that sent the campaign** replies. Do not switch identities mid-thread.
7. **Pause the sequence** on any live human thread.
