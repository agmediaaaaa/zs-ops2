## The 3 Inbox Management Rules

| Rule | Trigger | Action & Objective |
| :--- | :--- | :--- |
| **Rule 1: Easy to Book** | Prospect indicates interest, asks to speak, provides availability, or sends a JD. | Do **not** re-pitch. Immediately propose **2 specific slots** or provide the calendar link. |
| **Rule 2: Question Asked** | Prospect asks a question (pricing, buyers, process, candidates) or gives soft pushback. | Answer concisely (**1–2 sentences**), then bridge to a 10–15 min call using an **incentive** (peer multiples, tailored candidate summary, zero risk). |
| **Rule 3: Unknown / Complex** | Regulatory, complex specs, union rules, high-tier pricing, mandate/registration questions. | Warmly intro Founder/CEO (**Jonathon Rapacki** / **Matt Arias**) while keeping the **booking hook** active. |

## Inbox Manager Quality Checklist

1. **Confirm Client & Campaign:** Never mix M&A language into Staffing threads or vice versa.
2. **Rule 1 (Easy Yes):** Lock calendar with 2 times or link. Never add qualification gates to someone ready to meet.
3. **Rule 2 (Questions):** Give a 1-sentence answer, then offer an incentive (peer benchmark / profile teaser) to book.
4. **Rule 3 (CEO Hand-off):** CC Jonathon Rapacki (GWS) or Matt Arias (MARS). Introduce as CEO/Founder and retain the booking link.

### Universal Tone & Execution

1. **Never Mix Niche Dictionaries**
   - GWS: targets, mandates, buyer interest, peer multiples — never "candidates / placements / resumes"
   - MARS: craft talent, workstations, overtime, tolerances — never "acquisitions / valuations"
2. **Never Add Friction to an Easy Yes** — if they say yes or suggest a day, lock it in immediately.
3. **Always Anchor Rule 2 with a Clear Incentive** — answer alone = ping-pong; answer + incentive = calls.
4. **Always Retain the Booking Hook on Rule 3** — never just say "I'll let them reply"; always include the founder's calendar link.
